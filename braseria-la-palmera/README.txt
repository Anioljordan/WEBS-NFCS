# Brasería La Palmera — Web

Proyecto web estático listo para subir a un hosting convencional.

## Archivos

- `index.html`
- `style.css`
- `script.js`
- `/img`

## Imágenes que debes colocar

Sustituye los placeholders de `/img` por tus fotos reales, manteniendo estos nombres:

- `logo.png` — logo del restaurante, preferiblemente PNG transparente.
- `favicon.png` — favicon del restaurante.
- `hero-brasa.jpg` — imagen principal horizontal, idealmente 1800×1200 o superior.
- `brasa-detalle.jpg` — detalle de parrilla/fuego/brasa.
- `plato-1.jpg` — foto vertical o cuadrada de un plato.
- `plato-2.jpg` — foto de un plato.
- `plato-3.jpg` — foto de un plato o menú diario.
- `interior.jpg` — interior, barra o ambiente.
- `madera-textura.jpg` — opcional; textura oscura de madera o detalle del local.

Si no sustituyes estas imágenes, la web mostrará el placeholder incluido.
